# Munchkin Power Tracker

A pixel-style phone app for tracking your level and gear bonuses in the card game Munchkin.

## What it does

- Level up and down from 1 to 10, with a win screen at 10
- Plus and minus buttons for each gear slot: Headgear, Armor, Footgear, Left Hand, Right Hand, and Big Item
- Extra items you can add, rename, and remove (potions, race or class bonuses, curses)
- Combat strength (level plus all bonuses) pinned to the top of the screen
- Saves your game on the device you're using

## How to use it

Open `index.html` in any browser. It's one file with nothing to install.
